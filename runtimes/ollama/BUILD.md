## Toolchain (as used)

- **Shell:** MSYS2, UCRT64 login shell.
- **Packages:** `mingw-w64-ucrt-x86_64-gcc` 16.2.0-3, `mingw-w64-ucrt-x86_64-cmake` (CMake 4.4.3), `mingw-w64-ucrt-x86_64-ninja`.
- **Git on PATH:** Ollama's patch step runs `git apply`, and MSYS2's default PATH has no git. With Git for Windows: `export PATH="$PATH:/c/Program Files/Git/cmd"` (Git 2.53.0 was used).

## Commands

```bash
git clone --depth 1 --branch v0.35.1 https://github.com/ollama/ollama ollama_src && cd ollama_src
cp /path/to/patches/003-hobbylm-bailingmoe2-decoupled-head-dim.patch /path/to/patches/004-win-exit-hang-stream-sessions-static.patch llama/compat/
cmake -S llama/server --preset cpu_windows -G Ninja     # clones llama.cpp b11232 and applies compat 001-004
cmake --build build/llama-server-cpu -j                 # about 4.5 min on an 8-core laptop
```

The `cpu_windows` preset builds shared libraries with `GGML_BACKEND_DL=ON`, `GGML_CPU_ALL_VARIANTS=ON` (one `ggml-cpu-*.dll` per x86-64 CPU family), `GGML_NATIVE=OFF`, `GGML_OPENMP=ON` and `LLAMA_CURL=OFF`.

## Assembly

1. **`ollama.exe`:** taken unchanged from the official Ollama v0.35.1 `ollama-windows-amd64.zip`.
2. **`lib/ollama/`, from `build/llama-server-cpu/bin`:**
   - `llama-server.exe`, `llama-quantize.exe`;
   - `libllama.dll`, `libllama-common.dll`, `libllama-server-impl.dll`, `libllama-quantize-impl.dll`, `libmtmd.dll`;
   - `ggml.dll`, `ggml-base.dll`, and all 14 `ggml-cpu-*.dll`.
3. **`lib/ollama/`, MinGW runtime DLLs from `C:\msys64\ucrt64\bin`:**
   - `libstdc++-6.dll`, `libgcc_s_seh-1.dll`, `libgomp-1.dll` (package `mingw-w64-ucrt-x86_64-gcc-libs` 16.2.0-3);
   - `libwinpthread-1.dll` (package `mingw-w64-ucrt-x86_64-libwinpthread` 14.0.0.r375.g9c1abbbf5-1).
4. **`lib/ollama/`, licence files:**
   - `LLAMA_CPP_LICENSE`: llama.cpp's `LICENSE`;
   - `LLAMA_CPP_VENDORS_LICENSE`: generated by the build at `build/llama-server-cpu/ollama-vendor-licenses/`.

The stock CUDA and Vulkan folders are not included.

**Self-containment:** every DLL imported by the files in this package is either in `lib/ollama/` or a Windows system DLL (checked with `objdump -p`).

**Reproducibility:** the build is not byte-reproducible, because absolute build paths are embedded. A rebuild in another folder produces different hashes. `MANIFEST_SHA256.txt` describes this build.
